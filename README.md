# AI Data Intelligence Platform

A public product shell for a RAG knowledge agent and a Text-to-SQL data agent.

## Quick Start

Windows: first double-click `SETUP_PLATFORM.bat`, then copy `.env.example` to `.env`, configure it, and double-click `START_PLATFORM.bat`. After setup, only `START_PLATFORM.bat` is needed.

The complete configuration, RAG modes, manual startup, ports, model bootstrap, and troubleshooting guide is in [docs/DEPLOYMENT.md](docs/DEPLOYMENT.md).
